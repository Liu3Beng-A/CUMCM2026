> **评级阈值（统一）**：A ≥ 85（优秀）/ B 70-84（良好）/ C 60-69（一般）/ D 50-59（偏差）/ E < 50（差）

## 4. Q1 方法亮点（5 件套）

| 方法 | 用途 | 输出 |
|------|------|------|
| **CRITIC + 业务 70:30 混合赋权** | 4 维度权重（变异性 + 冲突性） | `q1_weights.json` |
| **百分位 + Z-Score 双轨评分** | 多方案对比（避免硬阈值偏置） | `q1_score.json` |
| **行业阈值绝对评分** | 单值绝对评分（避免退化） | 同上 |
| **Prophet 反事实** | 假日贡献量级与显著性 | `q1_prophet_cost.png` |
| **Bootstrap 分级扣分** | 注入显著性到综合评分（春节 -12 / 国庆 -9 / 端午 -4 / 劳动节 -4 / 中秋 -2 = 原始 -31 封顶 -30） | `q1_holiday_penalty.json` |

辅助方法：龙卷风 + 敏感性曲线（权重稳健性）、5×4 热力图（总览）、跳出率 KMeans 聚类（关键词质量分组）、2025-08-21 异常日剔除对比（鲁棒性）。

## 5. 关键发现

1. **方案 500635396 是绝对主力**（59.0% 预算，84.15 万元）但 CPC 最高（2.24 元）且上方位 CTR 偏低（4.1%），存在"花得多却未挤进首位"的成本浪费。
2. **关键词有效率 60.04%**——890 个关键词"挂在那里却无人点击"，存在显著资源浪费。
3. **极度长尾集中**：前 20% 关键词贡献 99.21% 消费。
4. **跳出率 73.4%**——但通过 KMeans 聚类发现"高跳出 ≠ 浪费"，62.9% 的"高跳出词"实际只花 0.8% 的钱。
5. **Bootstrap 显著负贡献节日**（按"节日聚合显著性天数"分级扣分，全量 37 节日 × 100 次）：**春节 -12 / 国庆 -9 / 端午 -4 / 劳动节 -4 / 中秋 -2**，原始合计 -31 分封顶 -30 分。
6. **方案 525368335（时间维度扣分前 35.07）**：3 月单月消费占全年 59.9%，月度预算 CV=2.057（健康区间 0.3-0.5），严重错位。

## 6. 4 种方法对比

| 方法 | Pearson | Spearman |
|------|---------|----------|
| 等权平均 | 0.9378 | 0.90 |
| 熵权法 | 0.9978 | 0.90 |
| 等权 TOPSIS | 0.8958 | 0.80 |
| **CRITIC（本文）** | **1.0000** | **1.00** |

5 个方案排名完全一致（500635396 > 63563817 > 495403620 > 495817671 > 525368335），**结论高度稳健**。
