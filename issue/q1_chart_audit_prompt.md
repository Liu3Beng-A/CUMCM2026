### 维度 C · 图表样式（25 分）

**审查方法**：对每张图，检查**视觉样式**：

| 子维度 | 评分点 |
|---|---|
| **配色** | 是否统一（参考 `src/plot_style.py` COLORS）；红黄绿语义是否合理；色盲友好 |

| **专业感** | 是否有合适的 dpi / figsize；边框是否多余；网格是否过密/过疏 |

- 配色：`COLORS = {'primary': '#...', 'accent': '#...', 'danger': '#...', 'success': '#...'}` 是否被合理使用

**特别关注**：
- 中文乱码（最常见的扣分点）
- 颜色映射与 colorbar 不一致
- 子图标题大小不一
- 0 分单元格在 heatmap 中应有红色边框（参考 `q1_heatmap.py` line 95-100）

**扣分典型情形**：
- 中文字体未注册，所有中文显示为方框
- 红绿配色但色盲不友好
- 子图标题/标签大小不一
- 0 分单元格未标记
