## 三、4 个审查维度（每维度 0–25 分，合计 100 分）

### 维度 A · 解决方案的科学性与合理性（25 分）

**审查点**：
1. **评分体系设计**：4 个维度的划分（设计质量 / 关键词 / 出价 / 时间）是否覆盖题目要求？二级指标选取是否有 SEM 行业依据？
2. **赋权方法**：CRITIC（数据驱动） + 业务 70:30 混合是否合理？权重结果是否合理？
3. **节日效应建模**：Prophet 反事实 + Bootstrap 显著性的方案是否科学？扣分规则（按节日聚合、封顶 -30）是否合理？
4. **辅助方法**：龙卷风 / 敏感性曲线 / 异常值鲁棒性 / KMeans 聚类 / 4 种方法对比 是否必要且恰当？
5. **对比基线**：与等权 / 熵权 / TOPSIS 的对比是否充分？CRITIC 的优势是否成立？

**扣分典型情形**：
- 维度划分主观无依据
- 赋权完全依赖"拍脑袋"或单一方法
- 显著性检验样本量过小（如 n_boot<30）
- 缺少与至少 2 种基线方法的对比
