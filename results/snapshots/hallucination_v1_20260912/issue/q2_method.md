## 2. 方法

### 2.1 特征工程（**5 维**，已删除"注册率"）

| 维度 | 计算公式 | 业务含义 |
|---|---|---|
| `log消费` | log1p(消费额) | 投入规模 |
| `CPC` | 消费额 / 点击量 | 单位获客成本 |
| `log展现` | log1p(浏览量) | 流量规模 |
| `点击率` | 点击量 / 展现量 | 创意吸引力 |
| `跳出率` | 跳出数 / 访问数（NaN → 中位数填充）| 落地页质量 |

**注（关键修订）**：注册转化率维度已删除。原代码构造 6 维特征，但 Sheet2 注册数据是"每日新注册数"（日期+方案粒度），关键词级不可用——该列在 `keyword_total.pkl` 中实际不存在，原 `prepare_features` 走 else 分支默认为 0。本文以"跳出率"作为转化质量的代理（跳出率与注册转化率通常呈强负相关）。

### 2.2 GMM + BIC + 多指标交叉验证选 K

- 算法：Gaussian Mixture Model（高斯混合）
- 协方差类型：full（最一般）
- 候选 K：2 ~ 8
- **主指标**：BIC 最小（Bayesian Information Criterion）
- **辅助指标**（交叉验证）：Silhouette / Davies-Bouldin / Calinski-Harabasz
- **实际最佳 K = 8**（BIC = -50850.1；CH = 937.0；BIC 与 CH 两个最稳健指标一致）

### 2.3 业务命名启发式（重写）

派生特征：**ROI = log展现 − log消费**（投入产出比，越大越好）

按优先级归入 5 业务类：

| 优先级 | 业务类 | 启发式条件 |
|---|---|---|
| P1 | 高成本浪费型 | 消费头部 + CPC 高 + 跳出高（最差，应暂停） |
| P2 | 高价值转化型 | 消费头部 + ROI 中/高（核心词，加大预算） |
| P3 | 潜力挖掘型 | 跳出率低 + ROI 中高 + 消费非零非最高（待优化爆款） |
| P4 | 稳定拓展型 | 中部消费 + ROI 中等 + 非死词（补量词，稳步扩） |
| P5 | 低效长尾型 | 兜底（含死词、尾部 ROI 低） |

**修订前问题**：原启发式循环依赖"注册率"判断潜力挖掘型，但注册率恒为 0 → 潜力挖掘型永远不会被激活。修订后用 ROI + 跳出率 联合判断，问题解决。

## 4. 选 K 多指标交叉验证

| K | BIC（越小越好） | Silhouette（越大越好）| Davies-Bouldin（越小越好） | Calinski-Harabasz（越大越好） |
|---|---|---|---|---|
| 2 | -33001.2 | 0.393 | **0.871** | 686.5 |
| 3 | -38917.4 | 0.436 | 1.523 | 572.2 |
| 4 | -46156.5 | 0.526 | 1.335 | 651.2 |
| 5 | -49515.7 | 0.568 | 1.530 | 664.2 |
| 6 | -49861.6 | **0.585** | 1.095 | 744.8 |
| 7 | -50458.7 | 0.560 | 1.261 | 846.9 |
| **8** | **-50850.1** | 0.562 | 1.117 | **937.0** |

**综合判断**：BIC 与 CH 一致指向 K=8；Silhouette 指向 K=6 但差距仅 0.023；Davies-Bouldin 指向 K=2 但 K=2 不切实际。**K=8** 是兼顾统计意义与业务可解释性的最优选择。

## 5. 论文可写要点

### 5.1 业务解读

- **高价值转化型**（黄金词，145 词）：核心词，应加大预算
- **稳定拓展型**（重点词，634 词）：补量词，可稳步扩
- **潜力挖掘型**（潜力词，122 词）：优化词，优化创意/落地页后可释放
- **高成本浪费型**（问题词，1 词）：应暂停（个案处理）
- **低效长尾型**（无效词，1325 词）：长期观察后清理

### 5.2 国一差异化

- 不止"4 象限 / 5 分类"硬阈值
- GMM 自适应选 K（不必拍脑袋选 5）
- 4 指标交叉验证（BIC + Silhouette + DB + CH）
- 业务命名让算法贴近业务
- 题面 5 类与业务 5 类显式映射（论文表 5-2）
