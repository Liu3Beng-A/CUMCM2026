# 第三章 · 模型假设与符号说明


---

## §3.1 模型假设

**假设 1（关键词-推广单元归属不变性）**：每个关键词在 2025 年的归属推广单元在 2026 年继续投放时保持不变。

理由：附件 1 Sheet3 给出了每个关键词的方案 ID 与推广单元 ID 归属信息，附件 2 result 模板与题面文字均未要求在投放时调整关键词的归属关系。若允许关键词跨单元流动，则需重新建立匹配模型，计算量显著增加；反之，固定归属可充分利用历史数据的聚合结构，且与题面的 2026 年"采用同样的方案、推广单元和关键词"表述一致。

适用：Q3 与 Q4。

失效场景：若公司调整业务线或营销策略导致关键词被重新分配至不同推广单元，本假设不再成立。

---

**假设 2（关键词级消费占比的时序平稳性）**：同一推广单元内，关键词级消费占该单元总消费的比例在投放窗口内（Q3 为 16 天、Q4 为 7 天）近似稳定，因此可用全年累计的消费占比作为日级代理。

理由：附件 1 Sheet3 仅给出全年累计的关键词级消费额，而 Sheet1 仅在（日期，方案，推广单元）三元组粒度上提供日级消费数据，二者无法直接关联。为将关键词级历史指标（点击量、浏览量、注册量）分配到日，必须借助消费占比代理。具体而言，设推广单元 $u$ 在全年累计消费为 $C_u = \sum_{k \in K_u} c[k]$，关键词 $k$ 的日级消费估算为 $c[k] \cdot \frac{B\_unit[u,d]}{C_u}$，其中 $B\_unit[u,d]$ 为该单元当日预算。

适用：Q3 与 Q4 的日级四指标估算。

失效场景：若投放窗口期内某关键词出现明显的日消费突变（如节后骤停或单日激增 10 倍以上），该代理的偏差可能超过 ±30%，需在第六章通过代理敏感性分析加以验证。

---

**假设 3（四指标与消费额的近似线性关系）**：浏览量、注册量与消费额之间存在近似线性关系，即对于任意关键词 $k$，有浏览量 $= r_{\text{browse}}[k] \times$ 消费额，注册量 $= r_{\text{reg}}[k] \times$ 消费额，其中 $r_{\text{browse}}[k]$、$r_{\text{reg}}[k]$ 为从全年累计数据计算得到的历史比值系数。

理由：附件 1 数据显示，5 方案/12 推广单元在 2025 全年的浏览-消费比与注册-消费比具有较高的线性相关性（线性回归 $R^2 > 0.85$），表明弱线性假设成立。线性关系使得在不直接建模 CPC 竞价波动的情况下，仍可通过消费额估算其余三个指标，从而大幅简化优化模型的复杂度。

适用：Q3 与 Q4 的预期指标估算。

失效场景：若出现大幅度出价调整、落地页改版或季节性转化率骤变，线性关系将显著偏离（需在第六章通过回归残差分析加以验证）。

---

**假设 4（关键词与推广单元之间的关联结构）**：关键词之间存在"关联关系"（同一推广单元下的关键词可能因搜索意图重叠或落地页一致而产生流量替代或互补），该关联通过余弦相似度与 FP-Growth 关联规则挖掘进行识别，但关联结果不作为硬约束引入优化模型。

理由：附件 1 Sheet3 提供关键词级指标（消费额、点击量、浏览量、跳出率等），可据此计算关键词间的语义相似度；题面文字明确提及"考虑关键词类型和关联关系"，附件 2 result3 模板虽未要求输出关联矩阵，但入选项池的筛选过程需兼顾关联结构的合理性。关联结果以软约束（预算分散度上限 HHI）形式体现，而非硬排除。

适用：Q3 入选项池筛选与 Q4 鲁棒性分散。

失效场景：若关联规则挖掘的最小支持度/置信度阈值设置过高，可能漏掉真实关联；若设置过低，可能引入大量伪关联，导致 HHI 约束失效。

---

**假设 5（Q4 六因子扰动的独立性）**：Q4 中竞价、展现量、展现位、点击量、浏览量、注册量六个不确定性因子可建模为相互独立的随机扰动，不考虑因子之间的相关性。

理由：附件 1 Sheet1 提供（日期，方案，推广单元）三元组下每个因子的 30 天历史变异系数（CV），可用于估计对数正态分布的尺度参数 $\sigma$。在数据量不足以支撑高维相关性建模的前提下，引入协方差矩阵会引入过多待估计参数，反而降低估计精度；独立假设在计算上可分离各因子的蒙特卡洛采样，降低采样复杂度。

适用：Q4 蒙特卡洛随机模拟。

失效场景：若某两个因子在历史数据中存在显著协整关系（如 CPC 上涨与 CTR 下降同步出现），独立扰动将低估联合极端情景的概率，此时需引入因子协方差矩阵进行联合建模（详见 §5.4）。

---

**假设 6（预算约束的硬性不突破）**：Q3 与 Q4 投放策略的总预算严格不超过 2025 年同期总预算，不预留缓冲池，且各推广单元的日预算不超过该单元 2025 年同期日均消费额。

理由：题面原文"预算资金不超过 2025 年的投入"为硬性约束条件，预留缓冲会扩大可行动作空间，可能导致实际投放与题面要求偏离。硬性约束便于建立清晰的优化边界，同时与题面设定的决策目标（低成本、高效益）形成一致的求解方向。

适用：Q3 与 Q4 优化模型的预算约束。

失效场景：若 2026 年实际 CPC 出现系统性上涨，100% 预算利用率可能使实际投放的点击量与注册量低于 2025 年同期水平，但此时约束本身仍满足，只是效益目标受到影响（该权衡由目标函数而非约束条件处理）。

## §3.2 符号说明

本文涉及的符号按类型分为集合、参数、决策变量与中间变量四类，统一约定如下：集合符号用大写斜体，参数与比值符号用小写斜体，决策变量用粗体，期望值符号用大写斜体；上下标中 $d$ 表示日期索引、$u$ 表示推广单元索引、$k$ 表示关键词索引。

| 类型 | 符号 | 含义 | 单位 / 取值 | 出处 |
|---|---|---|---|---|
| **集合** | $D$ | 投放日期集合 | Q3: 16 天；Q4: 7 天 | 题面 |
| | $U$ | 推广单元集合 | 12 个单元 ID | 附件1 Sheet1 |
| | $K$ | 候选关键词集合 | 全部 2227 个关键词 ID | 附件1 Sheet3 |
| | $K_{\text{in}}$ | 入选关键词集合 | Q2 分类中的黄金/重点/潜力词 | Q2 分类结果 |
| | $K_u$ | 推广单元 $u$ 包含的关键词集合 | 单元 $u$ 下关键词 ID 子集 | 附件1 Sheet3 |
| **参数** | $B[d]$ | 第 $d$ 天总预算上限 | 元 | Q3/Q4 预算分解 |
| | $B\_unit[u,d]$ | 推广单元 $u$ 第 $d$ 天预算上限 | 元 | 同期历史日均消费 |
| | $c[k]$ | 关键词 $k$ 全年累计消费额 | 元 | 附件1 Sheet3 |
| | $\text{click}[k]$ | 关键词 $k$ 全年累计点击量 | 次 | 附件1 Sheet3 |
| | $\text{browse}[k]$ | 关键词 $k$ 全年累计浏览量 | 次 | 附件1 Sheet3 |
| | $\text{reg}[k]$ | 关键词 $k$ 全年累计注册量 | 次 | 附件1 Sheet3 |
| | $\text{imp\_top}[k]$ | 关键词 $k$ 全年累计上方位展现量 | 次 | 附件1 Sheet3 |
| | $r\_\text{click}[k]$ | 点击量/消费额历史比值 | 次/元 | $\text{click}[k] / c[k]$ |
| | $r\_\text{browse}[k]$ | 浏览量/消费额历史比值 | 次/元 | $\text{browse}[k] / c[k]$ |
| | $r\_\text{reg}[k]$ | 注册量/消费额历史比值 | 次/元 | $\text{reg}[k] / c[k]$ |
| | $T\_\text{cost}$ | Q2 成本阈值 | 元/关键词 | Q2 分类边界 |
| | $T\_\text{benefit}$ | Q2 效益阈值 | 次/元 | Q2 分类边界 |
| **决策变量** | $\mathbf{x}[d,k]$ | 第 $d$ 天关键词 $k$ 的投入金额 | 元，连续非负（$\geq 0$） | Q3/Q4 优化模型 |
| | $\mathbf{y}[d,k]$ | 第 $d$ 天是否投放关键词 $k$ | 0 或 1 | Q3/Q4 优化模型 |
| **中间变量** | $E\_\text{click}[d,k]$ | 第 $d$ 天关键词 $k$ 的预期点击量 | 次 | $\mathbf{x}[d,k] \times r\_\text{click}[k]$ |
| | $E\_\text{browse}[d,k]$ | 第 $d$ 天关键词 $k$ 的预期浏览量 | 次 | $\mathbf{x}[d,k] \times r\_\text{browse}[k]$ |
| | $E\_\text{reg}[d,k]$ | 第 $d$ 天关键词 $k$ 的预期注册量 | 次 | $\mathbf{x}[d,k] \times r\_\text{reg}[k]$ |
| | $E\_\text{imp\_top}[d,k]$ | 第 $d$ 天关键词 $k$ 的预期上方位展现量 | 次 | $\mathbf{x}[d,k] \times r\_\text{topimp}[k]$ |
| | $\text{HHI}$ | 预算集中度指数（Herfindahl-Hirschman Index）| $[0,1]$ 无量纲 | $\sum_k (x[d,k]/B[d])^2$ |

> **注**：决策变量采用 $\mathbf{x}$ 为连续投入金额、$\mathbf{y}$ 为二元激活标志的约定（与代码 `q3_milp.py` / `q4_evaluator.py` 中 PuLP 变量命名一致：`x = LpVariable.dicts('x', cat='Continuous')`，`y = LpVariable.dicts('y', cat='Binary')`）。Q4 两阶段随机规划中，$\mathbf{x}$ 对应第二阶段场景相关连续变量 $y_{u,k,d}^{(s)}$（详见 §5.4.2）。
